## 🚀 Key Features

* **50 Premium Templates:** Divided into highly curated categories: *The Corporate, The Creative, The Startup, The Academic, and The Elite Collections.*
* **Adaptive Desktop UI:** Running on a PC or Tablet? The app automatically snaps into a pro-level split-screen mode, showing your data entry on the left and a live, real-time PDF preview on the right.
* **Smart Auto-Suggest Engine:** Save time typing. The app features built-in autocomplete for common tech roles, top global universities, standard degrees, and major corporations.
* **100% Offline & Secure:** Your personal data never leaves your device. The PDFs are generated instantly on-device using the native Dart `pdf` engine.
* **Smart Pagination & Spacing:** Text dynamically wraps and flows across multiple pages without breaking the template's design constraints.
* **One-Click Backup:** Export and import your entire resume database as a secure JSON backup.

## 💻 Getting Started

Want to run this project locally or contribute? 

### Prerequisites
* [Flutter SDK](https://flutter.dev/docs/get-started/install) installed on your machine.
* Ensure you have the required toolchains installed for your target platform (e.g., Visual Studio with C++ workloads for Windows, Xcode for macOS).

### Installation
1. Clone the repository:
   git clone https://github.com/manjeetdeswal/resume_builder.git

2. Navigate to the directory:
   cd resume_builder

3. Install dependencies:
   flutter pub get

4. Run the app:
   flutter run
